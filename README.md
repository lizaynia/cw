# 🛫 Airport Management System

Курсовая работа: Многопоточная клиент-серверная система управления аэропортом на Java.

## 🚀 Инструкция по запуску

Для успешного запуска системы выполните следующие шаги:

### 1. Подготовка Базы Данных
1. Убедитесь, что у вас установлен **MySQL Server**.
2. Создайте базу данных с названием `airport_db`.
3. Выполните SQL-скрипт инициализации, который находится по пути:
   `Server/src/main/resources/init_db.sql`
4. Проверьте настройки подключения в файле `Server/src/main/resources/hibernate.cfg.xml`. 
   *При необходимости измените `connection.username` и `connection.password` на ваши.*

### 2. Сборка проекта
В корневой директории проекта выполните команду:
```bash
mvn clean install
```
*Это соберет все модули (Shared, Server, Client) и установит их в локальный репозиторий.*

### 3. Запуск Сервера
1. Перейдите в модуль **Server**.
2. Запустите главный класс: `com.server.Server`.
3. В консоли должно появиться сообщение: `Сервер запущен и ожидает подключений`.

### 4. Запуск Клиента
1. Перейдите в модуль **Client**.
2. Запустите главный класс: `com.client.ClientApp`.
3. Откроется окно авторизации.
